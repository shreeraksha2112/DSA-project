📘 DSA Concepts Used

🔺 Min-Heap

Priority queue that surfaces soonest-expiring medicines first. Push/Pop: O(log n). Urgency = days × regulatory_penalty. Ensures we always process the most at-risk medicines before anything else.

🌐 Weighted Graph

Transport network modeled as undirected graph. Edge weights combine Haversine distance + cold-chain multiplier + controlled-substance surcharge. Supports Dijkstra's shortest path for route optimization.

🔗 Bipartite Matching

Left partition: (donor, medicine) surplus. Right partition: receiver demand. Feasible edges are ranked by net benefit, with stock and demand capacities enforced as assignments are made.

🎯 Greedy Allocation

Process medicines in heap order (most urgent first). For each, find the nearest compatible receiver. O(n × m) time complexity. Faster but may miss globally optimal combinations.
